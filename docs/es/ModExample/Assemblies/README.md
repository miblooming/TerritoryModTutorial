# DLL y código: Assemblies

[Tutorial principal](../../README.md) · [Estructura de carpetas](../README.md) · [Original en chino](../../../../ModExample/Assemblies/README.md)

Coloca aquí las DLL compiladas que añaden o modifican funciones del juego. La carpeta debe estar dentro de tu mod, por ejemplo: `Mi_Mod/Assemblies/`.

## Cuándo necesitas esta carpeta

No todos los mods necesitan código. La guía principal indica que los cambios de configuración, imágenes o contenido mediante datos pueden hacerse sin generar una DLL.

Si tu cambio se limita a textos traducidos, empieza por [Languages](../Languages/README.md). Para objetos, recetas y parámetros, consulta [Defs](../Defs/README.md). Si tu mod sí incluye código, coloca sus DLL en `Assemblies` antes de probarlo.

> **Alcance de esta página:** el original solo indica dónde guardar las DLL. Esta explicación añade contexto de la guía principal; no describe cómo crear un proyecto de C#, resolver sus dependencias o compilarlo.

Continúa con las [instrucciones para probar el mod](../../README.md#6-probar-el-mod-durante-el-desarrollo).
