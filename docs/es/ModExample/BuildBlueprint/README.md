# Planos de construcción: BuildBlueprint

[Tutorial principal](../../README.md) · [Estructura de carpetas](../README.md) · [Original en chino](../../../../ModExample/BuildBlueprint/README.md)

Usa esta carpeta para compartir planos de construcción mediante un mod.

## Copiar un plano al mod

1. Abre el juego y pulsa `F8` para acceder a la carpeta donde se guardan las partidas y los datos del usuario.
2. Busca el plano que quieras compartir en `TerritoryArchive/UserData/build_blueprint`.
3. Copia el plano a `BuildBlueprint`, dentro de la carpeta de tu mod.

Cuando otro jugador active el mod, podrá ver el plano que has incluido.

Para distribuirlo, completa también los [metadatos del mod](../About/README.md) y sigue las [instrucciones de publicación](../../README.md#publicar-o-actualizar-en-workshop).
