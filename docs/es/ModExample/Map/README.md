# Mapas personalizados: Map

[Tutorial principal](../../README.md) · [Estructura de carpetas](../README.md) · [Original en chino](../../../../ModExample/Map/README.md)

Usa esta carpeta para compartir mapas personalizados mediante un mod.

## Copiar un mapa al mod

1. Abre el juego y pulsa `F8` para acceder a la carpeta donde se guardan las partidas y los datos del usuario.
2. Busca el mapa personalizado que quieras compartir en `TerritoryArchive/UserData/map`.
3. Copia el mapa a `Map`, dentro de la carpeta de tu mod.

Cuando otro jugador active el mod, podrá comenzar una partida nueva en ese mapa.

Para distribuirlo, completa también los [metadatos del mod](../About/README.md) y sigue las [instrucciones de publicación](../../README.md#publicar-o-actualizar-en-workshop).
